CODING AGENT PROMPT — NIGHTTIME STREETLIGHT SYNTHETIC DATA GENERATION PIPELINE

You are implementing a reproducible synthetic-data generation pipeline for the Nighttime Streetlight Detection project.

The accompanying document Streetlight_Data_Synthesis_Plan.docx is the conceptual specification for this work. Read it completely before modifying any code.

Your task is to implement the data-generation pipeline described below, integrate it cleanly with the existing repository, and provide a CLI that allows the synthesis process to be configured without modifying source code.

Do NOT begin by generating the full dataset. First inspect the existing repository, dataset structure, annotation format, image dimensions, existing preprocessing/augmentation code, and any existing frame-extraction utilities. Reuse existing project conventions where appropriate.

The objective is to generate synthetic counterfactual nighttime images in which the illumination state of real streetlights is modified while the underlying physical scene remains unchanged.

The fundamental principle is:

SAME REAL SCENE
    ↓
SAME STREETLIGHT GEOMETRY
    ↓
CHANGE ONLY ILLUMINATION STATE
    ↓
working / dim / severely dim / flickering / off

The detector must therefore learn that:

streetlight identity ≠ brightness

rather than learning:

bright light source = streetlight

The synthetic dataset must be reproducible, auditable, and suitable for a research paper.

7. DUPLICATE / REDUNDANCY FILTERING

Implement two levels of redundancy filtering.

LEVEL 1 — temporal filtering

Reject candidate frames that occur too close to a previously selected frame from the same source video.

The threshold must be configurable.

For example:

temporal_exclusion_seconds = 1.0

Do not hard-code this value.

LEVEL 2 — visual filtering

Use a lightweight perceptual similarity mechanism.

Recommended progression:

exact hash
    ↓
perceptual hash
    ↓
optional stronger comparison for borderline cases

The exact method can be selected based on existing dependencies.

Do NOT blindly compare every candidate against every existing frame if this creates an O(N²) bottleneck.

Use a practical indexing/windowing strategy.

The objective is:

remove near-identical frames

not:

maximize mathematical image diversity at any cost.

The thresholds must be configurable.

The system must log how many candidates were removed by:

exact duplicate filtering
temporal filtering
perceptual filtering

8. SCENE DIFFICULTY / CONFOUNDER CLASSIFICATION

The synthetic dataset must contain approximately:

60% ordinary scenes
40% confounder-heavy scenes

The confounder-heavy scenes should preferably be REAL frames that already contain strong competing light sources.

Relevant confounders include:

vehicle headlights
brake lights
illuminated shop signs
storefronts
illuminated windows
traffic signals
advertisements
road reflections
strong glare
dense nighttime traffic
multiple unrelated bright objects

Do NOT artificially create confounders merely to satisfy the 40% requirement.

Prefer real confounder-rich source frames.

Implement an automatic confounder-scoring mechanism where practical.

However, do not pretend that the automatic classifier is semantically perfect.

The implementation should therefore support:

automatically classified scenes

and optionally:

manually approved scene categories

if a human-curated CSV/JSON is provided.

For example:

scene_id,category
scene_001,confounder_heavy
scene_002,ordinary

The manually supplied classification must override automatic classification.

The system should report:

total ordinary candidates
total confounder-heavy candidates
selected ordinary candidates
selected confounder-heavy candidates

If there are insufficient confounder-heavy candidates to satisfy 40%, DO NOT fabricate the ratio silently.

Instead issue a clear warning/error describing the shortage.

============================================================
9. STREETLIGHT REGION SELECTION

Use existing annotations wherever possible.

The transformation should primarily target the luminous lamp/halo region.

Do NOT simply darken the entire streetlight bounding box if that bounding box contains a substantial portion of the physical pole.

The desired conceptual decomposition is:

physical structure
      +
luminous component

The luminous component should be modified.

The pole/physical structure should remain.

If the dataset contains a dedicated Bulb/Halo Only annotation, use it as the primary illumination region.

If only a Full Streetlight bounding box exists, implement a conservative fallback and clearly document it.

Do not invent a precise pixel-level lamp mask from a bounding box and then claim that it is ground-truth segmentation.

Any automatically generated soft mask must be explicitly treated as a synthesis mask.

============================================================
10. SOFT ILLUMINATION MASK

The transformation must use a soft spatial mask.

Never perform:

image[y1:y2, x1:x2] *= alpha

with a hard rectangular boundary as the primary implementation.

Instead construct a smooth mask:

M(x,y) ∈ [0,1]

with:

M ≈ 1

near the luminous source and

M → 0

smoothly away from it.

The mask should preferably be based on the bulb/halo region.

Possible implementation:

binary region
    ↓
distance transform / Gaussian smoothing
    ↓
normalized soft mask

The exact implementation may be selected based on image-processing libraries already used by the repository.

The mask must be visualized during preview generation.

============================================================
11. DIM TRANSFORMATION

Implement:

T_dim(I, M, α)

Conceptually:

I'(x) = I(x) * [1 - M(x) * (1 - α)]

where:

α ∈ (0,1)

is the residual illumination factor.

Interpretation:

α = 1.0 → unchanged
α ≈ 0.7 → mildly dim
α ≈ 0.4 → moderately dim
α ≈ 0.15 → severely dim

These values are examples, not mandatory fixed values.

Use configurable ranges.

The transformation must:

preserve geometry
preserve object boundaries
preserve the pole
preserve unrelated objects
avoid hard mask boundaries

Do not use a single fixed α for every image.

Sample from configurable severity ranges using the configured random seed.

============================================================
12. OFF TRANSFORMATION

Implement:

T_off(I, M)

The off transformation should remove most direct luminous emission while retaining the physical streetlight structure.

Do NOT:

erase the streetlight
replace the streetlight with background
black out the whole bounding box

The desired result is:

bright lamp
    ↓
physically present but non-emitting lamp

The pole and fixture should remain visible whenever they were visible in the original.

The halo should be strongly suppressed.

Use conservative local attenuation rather than global scene darkening.

============================================================
13. FLICKER TRANSFORMATION

Implement flickering as a family of illumination states.

Do not merely apply random image noise.

The important variable is illumination intensity.

For example:

high
medium-high
medium-low
low
near-off

For a single image, generate one plausible flicker state.

If temporal source frames are available, optionally support temporal flicker sequences in a later extension.

Do not make perfectly periodic flickering a requirement.

Randomize intensity using configurable distributions.

Record the sampled flicker parameters in metadata.

============================================================
14. MIXED STREETLIGHT STATES

Implement an optional mixed mode in which different streetlights in one frame receive different illumination states.

Example:

Streetlight A → working
Streetlight B → dim
Streetlight C → off
Streetlight D → severe dim

This is useful because real roads may contain partially failed lighting systems.

Do not apply transformations to every streetlight automatically.

Select a configurable subset of eligible lights.

25. PRECISE PSEUDOCODE

Use the following pseudocode as the logical specification.

MAIN PIPELINE

FUNCTION main(config):

set_global_seed(config.random_seed)

repo_info = inspect_repository()

validate_configuration(config, repo_info)

source_records = load_source_records(
    image_dir=config.input_images,
    annotation_dir=config.input_annotations
)

IF config.source_manifest EXISTS:
    source_records = attach_source_provenance(
        source_records,
        config.source_manifest
    )

candidates = []

FOR record IN source_records:

    IF record.split IN ["val", "test"]:
        CONTINUE

    IF record.is_invalid:
        CONTINUE

    IF has_eligible_streetlight(record):
        candidates.append(record)

candidates = temporal_duplicate_filter(
    candidates,
    exclusion_seconds=config.temporal_exclusion_seconds
)

candidates = perceptual_duplicate_filter(
    candidates,
    threshold=config.perceptual_duplicate_threshold
)

scene_labels = classify_scene_difficulty(
    candidates,
    manual_labels=config.manual_scene_labels
)

ordinary = FILTER candidates WHERE
    scene_labels[id] == "ordinary"

confounder_heavy = FILTER candidates WHERE
    scene_labels[id] == "confounder_heavy"

selected = select_source_frames(
    ordinary=ordinary,
    confounder_heavy=confounder_heavy,
    desired_confounder_fraction=0.40,
    desired_total=config.number_of_source_frames,
    seed=config.random_seed
)

generation_records = []

FOR source IN selected:

    annotations = load_annotations(source)

    eligible_lights = extract_eligible_streetlights(
        annotations,
        class_mapping=repo_info.class_mapping
    )

    IF eligible_lights IS EMPTY:
        CONTINUE

    number_of_variants = sample_variant_count(
        config.number_of_variants_per_source
    )

    FOR variant_index IN range(number_of_variants):

        rng = create_deterministic_rng(
            config.random_seed,
            source.id,
            variant_index
        )

        state = sample_illumination_state(
            config.state_probabilities,
            rng
        )

        selected_lights = select_lights(
            eligible_lights,
            state=state,
            config=config,
            rng=rng
        )

        synthetic_image = copy(source.image)

        transformation_records = []

        FOR light IN selected_lights:

            region = determine_luminous_region(
                light,
                annotations
            )

            soft_mask = create_soft_illumination_mask(
                region,
                image_shape=source.image.shape,
                config=config
            )

            IF state == "dim":
                severity = sample_dim_severity(rng, config)

                synthetic_image = apply_dim(
                    synthetic_image,
                    soft_mask,
                    severity
                )

            ELSE IF state == "severe_dim":
                severity = sample_severe_dim_severity(rng, config)

                synthetic_image = apply_dim(
                    synthetic_image,
                    soft_mask,
                    severity
                )

            ELSE IF state == "flicker":
                severity = sample_flicker_state(rng, config)

                synthetic_image = apply_flicker_state(
                    synthetic_image,
                    soft_mask,
                    severity
                )

            ELSE IF state == "off":
                synthetic_image = apply_off(
                    synthetic_image,
                    soft_mask,
                    config
                )

            transformation_records.append({
                "light_id": light.id,
                "state": state,
                "severity": severity_if_defined
            })

        synthetic_annotations = copy_annotations(
            annotations
        )

        IF illumination_masks_exist(annotations):
            synthetic_annotations = handle_illumination_masks(
                source_annotations=annotations,
                synthetic_image=synthetic_image,
                transformations=transformation_records,
                config=config
            )

        synthetic_id = generate_synthetic_id(
            source,
            variant_index,
            state
        )

        output_image_path = save_image(
            synthetic_image,
            synthetic_id,
            config.output_images
        )

        output_annotation_path = save_annotations(
            synthetic_annotations,
            synthetic_id,
            config.output_annotations
        )

        metadata = create_metadata(
            synthetic_id=synthetic_id,
            source=source,
            state=state,
            transformations=transformation_records,
            seed=config.random_seed,
            generation_version=config.generation_version
        )

        save_metadata(metadata, config.output_metadata)

        IF config.generate_preview:
            save_preview(
                original=source.image,
                mask=combined_masks,
                synthetic=synthetic_image,
                metadata=metadata
            )

        generation_records.append(metadata)

report = generate_dataset_report(
    source_records=source_records,
    candidates=candidates,
    selected=selected,
    generated=generation_records
)

save_report(report)

print_report(report)

FUNCTION select_source_frames(
ordinary,
confounder_heavy,
desired_confounder_fraction,
desired_total,
seed
):

target_confounded =
    ROUND(desired_total * desired_confounder_fraction)

target_ordinary =
    desired_total - target_confounded

IF len(confounder_heavy) < target_confounded:
    WARN(
        "Insufficient confounder-heavy source frames."
    )

    target_confounded = len(confounder_heavy)

    target_ordinary =
        MIN(
            len(ordinary),
            desired_total - target_confounded
        )

selected_confounded =
    diversity_aware_sample(
        confounder_heavy,
        target_confounded,
        seed
    )

selected_ordinary =
    diversity_aware_sample(
        ordinary,
        target_ordinary,
        seed
    )

RETURN selected_confounded + selected_ordinary
DUPLICATE FILTER

FUNCTION temporal_duplicate_filter(records, exclusion_seconds):

selected = []

group records BY source_video

FOR each video_group:

    SORT video_group BY source_timestamp

    last_selected_timestamp = NULL

    FOR record IN video_group:

        IF record.source_timestamp IS NULL:
            selected.append(record)
            CONTINUE

        IF last_selected_timestamp IS NULL:
            selected.append(record)
            last_selected_timestamp =
                record.source_timestamp
            CONTINUE

        IF (
            record.source_timestamp -
            last_selected_timestamp
        ) >= exclusion_seconds:

            selected.append(record)

            last_selected_timestamp =
                record.source_timestamp

RETURN selected

FUNCTION perceptual_duplicate_filter(records, threshold):

selected = []

FOR record IN records:

    fingerprint = compute_perceptual_fingerprint(
        record.image
    )

    IF no_similar_selected_image(
        fingerprint,
        selected,
        threshold
    ):
        selected.append(record)

RETURN selected
SOFT MASK

FUNCTION create_soft_illumination_mask(region, image_shape, config):

binary_mask = rasterize_region(
    region,
    image_shape
)

expanded_mask = optional_region_expansion(
    binary_mask,
    config.mask_expansion
)

soft_mask = gaussian_blur(
    expanded_mask,
    sigma=config.mask_sigma
)

soft_mask = normalize_to_0_1(
    soft_mask
)

RETURN soft_mask
DIM

FUNCTION apply_dim(image, mask, severity):

residual = severity

attenuation =
    1 - mask * (1 - residual)

output = image * attenuation

output = clip_to_valid_image_range(output)

RETURN output
OFF

FUNCTION apply_off(image, mask, config):

residual = config.off_residual_intensity

attenuation =
    1 - mask * (1 - residual)

output = image * attenuation

output = clip_to_valid_image_range(output)

RETURN output
FLICKER

FUNCTION apply_flicker_state(image, mask, flicker_level):

residual = flicker_level

attenuation =
    1 - mask * (1 - residual)

output = image * attenuation

output = clip_to_valid_image_range(output)

RETURN output
DETERMINISTIC RNG

FUNCTION create_deterministic_rng(global_seed, source_id, variant):

derived_seed =
    stable_hash(
        global_seed,
        source_id,
        variant
    )

RETURN RNG(derived_seed)
ANNOTATIONS

FUNCTION copy_annotations(source_annotations):

destination_annotations =
    deep_copy(source_annotations)

RETURN destination_annotations
QUALITY CONTROL

FUNCTION validate_synthetic_sample(
original,
synthetic,
masks,
annotations
):

CHECK dimensions(original, synthetic)

CHECK no_nan_values(synthetic)

CHECK pixel_range(synthetic)

CHECK annotations_valid(annotations)

CHECK mask_bounds_valid(masks)

CHECK no_unexpected_geometry_change(
    original,
    synthetic
)

RETURN validation_result
